## 整页 AI 翻译偶发回显日语（定位 + 修复）
- 现象：开了 Reader Translation (AI) 的 Full-page translation 后，部分段落下方的译文仍是日文；长按单句翻译正常。
- 根因：整页翻译以「段落」为单位（`hoshi-web/reader/reader-translation.js` 的 `collectVisibleTargets` 收集
  `p, li, blockquote, figcaption, h1-h6, dt, dd`），默认段落 prompt 强调 keep every sentence in order / 不要省略合并，
  模型遇到拟声词、短促对话、标题、图注、引语或难句时倾向照抄/做「原文+译文」对照；长按走 sentence prompt + 单句输入，所以正常。
- 修复：`AdvancedAiClient.translatePageParagraph` 增加结果校验（新文件 `AdvancedAiTranslationGuard.kt` 的
  `isChineseTargetTranslation`：去空白后与原文相同、假名占比 ≥15%、含假名原句片段 ≥8 字被原样回显 → 判无效）；
  无效则用带「严格要求：每句翻简体中文，禁止引用日语原句/编号/逐句对照」的 user content 重试一次；两次都无效则
  `error()` → 上层 `markFailure`，不写缓存也不显示（宁可不显示，也不要显示"日文译文"）。
- 顺带：强化 en/zh 默认 `advanced_ai_default_page_paragraph_translation_prompt`，并把旧的 en/zh 默认文案加入
  `LEGACY_PAGE_PARAGRAPH_TRANSLATION_PROMPTS`，保证老用户自动迁移到新默认值。
- 验证：`gradlew test` 全绿、`gradlew :app:assembleDebug` BUILD SUCCESSFUL。当时 git 仍处于未完成的 merge 状态，
  未提交，避免顺手产生 merge commit。

## 整页 AI 翻译的其余缺陷（已全部修复，2026-09-18）
按用户优先级 2→1→3→4/5 修复：
- **错位（问题1）**：JS `ensureTargetId` 改为基于段落文本内容的稳定哈希 id（同章内相同文本加 `-n` 后缀去重），
  DOM 重建/restore 后同一段落仍命中同一缓存，不再错位。
- **性能/跳位（问题2）**：JS `applyTranslation` 不再每次无条件 `refreshReaderLayout()`；改为连续同步 apply 用
  `setTimeout(0)` 合并成一次刷新（`scheduleTranslationLayoutRefresh`），新增 `flushTranslationLayout()`；
  缓存重放时为相同内容做 no-op，避免反复全章重排。
- **抖动与浪费（问题3）**：翻页 `LaunchedEffect(chapterKey)` 不再 cancel 在途 job，只 `clearActiveWork()`；
  Coordinator 的 in-flight 记录改按"发起章节"匹配（`inFlightChapterKey`），翻页后旧在途请求仍能缓存到原章节而非被丢弃；
  pump 改为可共存的 worker（去掉单 job 门控），`pollNext()` 串行保证只有一个真正翻译。
- **失败可见 + 手动重译（问题4/5）**：`markFailure` 现在在页面显示"翻译失败，长按重试"占位块（CSS
  `.hoshi-reader-translation-failed`），并写入 Coordinator 失败记录（30s 退避，避免滚动回来反复打接口）；
  失败块带 `.hoshi-reader-translation` 类，长按即可 `requestSingleReaderPageTranslation` 重译覆盖。新增字符串
  `reader_translation_ai_page_translation_failed`（默认英文 + values-zh-rCN）。
- 验证：`gradlew testDebugUnitTest` 中 `ReaderPageTranslationCoordinatorTest` 7 项全绿（含退避、在途按发起章节缓存）；
  `compileDebugKotlin` 通过；`assembleDebug` BUILD SUCCESSFUL；APK 已 `adb install -r` 到 `S101022210032` 待用户验收。
- 预先存在的无关失败：`ReaderSettingsTest.publisherRenderSpecLeavesFamilyStyleAndWeightUntouched`（字体 CSS 渲染，与本次无关）。
- 有意 API 变更：`ReaderPageTranslationCoordinator` 的 `markSuccess/markFailure` 去掉 `chapterKey` 参数（改内部
  `inFlightChapterKey`）；`pollNext()` 不再接收 chapterKey；`pumpReaderPageTranslationQueue()` 无参；调用方在
  `ReaderWebView.kt`。

## 整页翻译 ANR 与长按重试修复（2026-09-18 补充）

`Choreographer: Skipped 35 frames` + `TextClassifier called on main thread` 大量。根因：
`pumpReaderPageTranslationQueue` 的 worker 跑在主线程（`rememberCoroutineScope`=AndroidUiDispatcher），
每段译文都 `evaluateJavascript` 派发 + 触发合并刷新（`warmPaginationMetrics` 在 WebView 渲染线程重排整章），
e-ink 上主线程/渲染线程过载导致触摸超时。修复：
- worker 主体移到 `Dispatchers.IO`，仅 `withContext(Dispatchers.Main.immediate)` 内派发 `evaluateJavascript`；
- `requestVisibleReaderPageTranslations` 的缓存重放改为单次批量 `applyTranslations(items)`（新增 Bridge 命令），减少 `evaluateJavascript` 次数。
- 长按手动重试（`requestSingleReaderPageTranslation`）绕过自动 guard：直接调
  `AdvancedAiClient.requestPageParagraphTranslation(strictChineseRendering=true)`，不再走 `translatePageParagraph` 的
  日语回显判定，信任用户意图（解决"长按失败块没反应"）。
- `AdvancedAiClient` 接口新增 `requestPageParagraphTranslation(settings, paragraph, strictChineseRendering=false)`，
  带默认实现 `= translatePageParagraph(...)`（测试 Fake 自动继承）；`OpenAiCompatibleAdvancedAiClient` override 提供真实 strict 逻辑。
- 验证：全量 `testDebugUnitTest` 1548 项通过（仅预先存在的 `ReaderSettingsTest.publisherRenderSpec...` 无关失败）；

## 新增墨水屏"刷新屏幕"功能（2026-09-18）
- 痛点：从桌面切回 app 时 e-ink 屏有浅层桌面残影（ghosting）。
- 设备 EB1004P（Rockchip, Android 11）暴露系统服务 `eink`（`android.os.IEinkManager`）；
  `setProperty("sys.eink.one_full_mode_timeline", <递增>) + setProperty("sys.eink.mode","2")`
  可触发全刷，但 `IEinkManager$Stub.asInterface` 与 `VMRuntime.setHiddenApiExemptions`
  均为 **blacklist**，普通应用进程反射被 denied，故厂商 API 在 app 内不可达。
- 实现：`features/eink/EinkScreenRefresh.kt` 优先尝试系统服务，失败回退全屏翻转 overlay
  （DecorView 叠全屏白层 400ms 再移除，依赖 driver 全屏更新触发 GC 清残影）。
- 入口：阅读器底栏菜单（Tune → 刷新屏幕）点击；`MainActivity.onResume` 自动触发（切回清残影）。
- 状态：已 build+install 到 S101022210032，运行不崩溃，残影是否真正清除待真机肉眼验证。
  若 overlay 无效，备选：设备若 root 则 app 内 `su -c "service call eink 4 s16 sys.eink.one_full_mode_timeline s16 1"`。
  补充（2026-09-18）：`IBinder.transact` 直连也受限——`TRANSACTION_setProperty` 字段同为 blacklist denied；
  设备未 root（`su` 不可用），root 路径排除。故 overlay 全屏翻转是当前唯一可行路径，残影清除效果待真机验证。
